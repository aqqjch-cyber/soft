## 0. 一页纸结论

| 项 | 结论 |
|---|---|
| 品类 | 单机 · 2D · 动作 Roguelite（俯视角，短局 8–12 分钟） |
| 题材 | 暗黑国风 / 民俗怪谈（傩面、灯市、纸扎），非西幻哥特 |
| 核心创意 | **生命 = 光源 = 视野 = 暴露度**，四者绑定在同一个"蜡烛"资源上 |
| 战斗节奏 | 暗行（安全但看不见）→ 点亮（能杀但被看见）→ 再入暗 |
| 局外 | 傩面（流派）× 蜡纹（词条）× 灯油（永久升级），死亡产出叙事碎片 |
| 技术 | Godot 4（首选）或 Unity；MVP 出 Web 版验证手感 |
| 上架形态 | **先 H5 / 小游戏"试玩版"上线 → 转 APK 或 PC 买断** |
| 收入 | 一期无内购（无版号限制），二期视资质走买断或内购 |
| MVP 周期 | 10 周（1 人全职）或 6 周（2 人） |
| 最大风险 | 玩法钩子不够直观（截图看不出爽点）；暗黑题材被评 16+ 影响分发 |

**一句话卖点**：你越接近死亡，越看不见；但越亮，越被盯上。

### 1.2 三条可行上架路线

| 路线 | 需要什么 | 收入 | 难度 | 适合阶段 |
|---|---|---|---|---|
| **A. 试玩版（推荐起步）** | 防沉迷接入 + 隐私政策 + 软著（建议有） | 无内购、无付费 | 低 | MVP / 验证期 |
| B. 正式上线 + 内购/买断 | 版号 + 软著 + ICP + 防沉迷 | 高 | 极高（个人几乎拿不到版号） | 成熟期 / 有发行商 |
| C. PC 买断（TapTap PC） | ISBN + 软著 + 正版验证 SDK | 零分成，仅 1% 手续费 | 高 | 有版号后 |

**结论**：一期走 A。不要一开始就赌版号。先用试玩版把"玩法成立 + 有真实玩家"这两件事做出来，这两件事本身就是拿版号、找发行、谈联运的筹码。

### 1.3 一期必须准备的合规项

1. **防沉迷**：接入 TapTap SDK 启动校验（快捷方案即可），录制官方要求的验证视频（无游客模式、未成年实名被拦、限时提示）。
2. **隐私政策**：独立页面、主体名与开发者一致、与游戏内一致，填入商店后台。
3. **适龄分级**：暗黑/惊悚内容建议主动标 **16+**，避免审核驳回。
4. **内容红线**：不出现真实宗教符号、不宣扬迷信（用虚构的"灯神/傩面"体系包裹）、无血腥特写、无自残暗示。
5. **素材版权**：字体（用开源可商用）、音乐（原创或授权）、音效（CC0 并留凭证）。

## 2. 市场与竞品：为什么是这个方向

### 2.1 榜单实况（2026-11-19 快照）

TapTap 独立游戏榜 / Roguelike 榜当前结构：

| 位置 | 游戏 | 观察 |
|---|---|---|
| 独立 #2 / 肉鸽 #2 | 元气骑士（8.6） | 像素地牢肉鸽，长线常青 |
| 独立 #5 / 肉鸽 #7 | 失落城堡2（7.4） | 多人联机动作肉鸽 |
| 独立 #7 | 鬼谷八荒（8.6，2025 TapTap 最佳独立游戏） | 沙盒修仙 |
| 独立 #8 | 土豆兄弟（6.4） | 割草弹幕 |
| 肉鸽 #1 | 群侠传：幸存者（9.3，测试） | 割草幸存者 + 武侠 |
| 肉鸽 #6 | 999秒!幸存者（9.1） | 极短局割草 |
| 肉鸽 #10 | 追迹迷城（9.4） | 2.5D 动作肉鸽，2026-08 公测 |
| 独立 #1 | Phigros（9.5） | 音游，非同类 |

**读出来的三件事**：
1. **肉鸽是 TapTap 的绝对主战场**，前十里 6 个是肉鸽/割草，且"幸存者割草"类扎堆 → 纯割草已红海。
2. **高分集中在"手感 + 单机 + 短局"**，评论里反复出现"打击感""局外养成合理"。
3. **国风暗黑有验证过的天花板**：暖雪（暗黑国风动作肉鸽）据其发行方与社区公开报道，全平台销量突破 300 万、Steam 好评率 92%+，手游版拿下 TapTap 年度最佳独立游戏并曾登顶热门榜 —— 说明这条赛道有真实容量。

**所以策略不是"再做一款割草肉鸽"，而是**：借肉鸽的成熟框架（玩家不用学），换一个别人没做过的**资源结构**做差异化。

### 2.2 差异化定位

| 维度 | 主流肉鸽 | 本作 |
|---|---|---|
| 视野 | 全屏可见，靠特效堆信息 | **视野即血量**，越虚弱越瞎 |
| 资源 | 血、蓝、钱三条独立 | **一条蜡烛**承担四种功能 |
| 战斗节奏 | 一直输出 | 暗/亮交替，**主动放弃视野换取杀伤** |
| 恐怖来源 | 跳吓、血浆 | **信息剥夺**（看不见 = 真恐惧，且合规友好） |

最后一条很关键：**用"看不见"制造恐怖，比用血腥更高级，也更容易过审。**

## 3. 核心创意：蜡烛的四重绑定

```
        蜡烛 (Wax)
       /    |    \      \
   生命值  视野半径  攻击权限  暴露度
```

一条资源，四个后果，互相拉扯：

- **蜡烛 ↓ → 视野 ↓**：光圈缩小，看不到拐角和敌人。
- **蜡烛 ↓ → 更安全**：敌人靠"光"索敌，光圈小 = 索敌范围小。
- **蜡烛 ↓ → 无法攻击**：点亮一击需要耗蜡，蜡不够就只能逃。
- **蜡烛 ↓ → 濒死**：归零即死。

于是自然长出核心张力：

> **你最强的时候最危险，你最安全的时候最无力。**

这一条就足以支撑一整款游戏，且**用一张截图就能讲清楚**（小光圈 vs 大光圈的对比图）——这对 TapTap 的转化率极其重要。

### 3.1 三条由此派生的机制

**① 剪灯芯（主动降亮）**
长按屏幕"剪灯芯"，光圈骤缩到极小，进入"盲行"：敌人丢失目标，你也失去视觉，靠声音与震动反馈定位。这是玩家唯一的"脱战"手段，也是高手操作空间。

**② 余烬（黑暗里的收益）**
在黑暗中停留会积累"余烬"。余烬可换：一次瞬发暗杀、一次强制点亮、或回复少量蜡。
→ 黑暗不再是"被动等待"，而是**主动经营**。

**③ 灯债（自我制造的敌人）**
每熄灭一盏场景灯，世界记一笔"灯债"。灯债在关卡结算时化为敌人强度或额外波次。
→ 玩家自己决定这一局有多难，**风险自选**，天然产生高手向的爽点与社区讨论点。

### 3.2 为什么不是"又一个光暗玩法"

- 市面上的光暗多是**技能效果**（照亮 = 增益）。
- 本作把光做成**代价**：亮 = 强 = 危险。这是价值反转，不是数值增减。
- 反转带来的是**决策**，不是**操作**。手机端最缺的是"能想的事"，最不缺的是"能点的事"。

## 4. 玩法系统

### 4.1 核心循环（单局 8–12 分钟）

```
进入灯区 → 摸黑侦察 → 选择目标（点灯/剪芯/绕行）
   → 点亮一击（耗蜡、暴露） → 清场或撤退
   → 拾取蜡/余烬/蜡纹 → 下一个灯区 → Boss → 结算
```

一局 = 3 个灯区 + 1 个 Boss 房。手机竖屏/横屏均可，建议**横屏**（动作游戏手感）。

### 4.2 资源与数值锚点（起始值，待调）

| 资源 | 起始 | 规则 |
|---|---|---|
| 蜡（生命） | 100 | 每秒自然燃 1（约 100 秒/局，靠击杀与拾取续命） |
| 光半径 | `12 + 18 × (蜡/100)` 像素单位 | 蜡 100% → 半径 30；蜡 10% → 半径 13.8 |
| 点亮一击 | 耗 6 蜡 | 造成 3 倍伤害，光圈短暂扩到 1.6 倍，持续 0.4 秒 |
| 剪灯芯 | 每秒 0.5 蜡 | 半径降至 8，敌人索敌半径降至 6 |
| 击杀回蜡 | +4 | 连杀 3 次额外 +6（鼓励激进） |
| 敌人索敌 | 光半径 × 0.9 | 在光圈内 1.2 秒后锁定 |

设计意图：**蜡多 = 好打但被围攻；蜡少 = 难打但能活**。玩家永远在两种痛苦间选一个。

### 4.3 敌人设计（全部围绕"光"做文章）

| 敌人 | 行为 | 教学目的 |
|---|---|---|
| 扑灯蛾 | 被光吸引，直线冲撞 | 教你"亮 = 危险" |
| 纸人 | 只在黑暗中移动，光下静止伪装 | 教你"黑 = 有东西" |
| 提灯伥 | 自带光源，走到哪亮到哪 | 教你"移动光源"要优先处理 |
| 剪影 | 只在你点亮时出现 | 教你"别乱亮" |
| 傩面本我（Boss） | 复制你上一局的 Build 与死法 | 教你"你的过去在杀你" |

**Boss 用玩家上一局的数据生成**——这是低成本高感知的设计：每个玩家的 Boss 都不一样，天然适合截图和讨论。

### 4.4 局外成长

| 层 | 内容 | 作用 |
|---|---|---|
| 傩面（角色） | 6 张，每张改一条核心规则 | 流派差异，如"盲面"：永久无视野，靠声呐；"笑面"：敌人不打你，但会偷你的蜡 |
| 蜡纹（词条） | 60+，局内三选一 | 构筑深度 |
| 灯油（永久） | 由"熄灭的灯"兑换 | 长线留存 |

**傩面是宣发核心**：一张面具一套规则，比"新角色 +10% 攻击"有传播力得多，也是美术最出彩的地方。

## 6. 美术与音频

### 6.1 视觉方向

- **色彩**：95% 黑白灰 + 单一暖橘（烛火）。极简调色板 = 低成本 + 高辨识度。
- **风格**：剪影 + 纸扎质感（宣纸、裱糊、毛边），傩面用粗线条符号。
- **技术做法**：全屏黑色遮罩 + 烛光半径做径向渐变挖洞（一个 shader 就能实现核心视觉）。
- **关键截图**：同一场景"满蜡/残蜡"两张对比图 → 直接就是商店首图。

### 6.2 音频（恐惧的主要载体）

- 无 BGM 或极简低频 drone；靠**环境声定位**（纸摩擦、水滴、脚步回声）。
- 剪灯芯时切掉高频（听觉上"世界变闷"），点亮时恢复 → 让玩家用耳朵感知状态。
- 手机端加**触感反馈**：蜡越少，心跳震动越强。这是低成本高感知的一招。

## 7. 叙事

- **形式**：碎片化、无配音、纯文本 + 静态插画。
- **载体**：**烛泪**。每次死亡，蜡滴落凝固，留下一片"记忆"。在营地回看，逐步拼出"长明灯为何熄灭"。
- **优势**：文本成本低、可后续加、天然形成"每死一次都有收获"的正反馈，缓解肉鸽挫败感。
- **禁忌**：不写真实宗教、不写现实地名、不做恐怖跳吓。

## 8. 技术方案

| 方案 | 优点 | 缺点 | 建议 |
|---|---|---|---|
| **Godot 4** | 2D 手感好、免费、导出 Web/PC/Android 一条龙、单人可维护 | TapTap 小游戏支持不如 Unity/Cocos 成熟 | **首选** |
| Unity | TapTap SDK / 小游戏链路最完整、生态大 | 体积大、Web 导出弱 | 若确定走小游戏则选它 |
| Cocos Creator | 小游戏导出最顺 | 2D 动作手感需自己打磨 | 若团队熟 Cocos |
| TapTap 制造 | 一键发布、零门槛 | 受平台引擎能力约束，深度动作可能受限 | 做原型 / 验证想法可以试 |

**推荐路径**：Godot 4 做核心 → 导出 Web 版先给玩家试玩 → 视数据决定是打 APK 还是移植 Unity 走小游戏。

### 8.1 MVP 技术范围（钉死，不许膨胀）

- 单场景、单角色、3 种敌人、1 个 Boss、1 层地图
- 无账号、无联网、无排行榜、无云存档
- 存档只存"灯油"和"已解锁傩面"（本地 JSON）

## 9. 上架执行路线（六步，顺序不可换）

来自 TapTap 官方 AI 接入文档（`developer.taptap.cn/agents.md`）：

| 步 | 动作 | 验收 |
|---|---|---|
| 1 | 建游戏（草稿） | 控制台可见，状态草稿 |
| 2 | 传包体 | 校验通过，能出测试二维码 |
| 3 | **先自测**（扫码连玩三局） | 无白屏、无卡死、无死路 |
| 4 | 补物料（图标/截图/简介） | 扫码看到的就是最终版 |
| 5 | 开测试计划（封闭/开放） | 真实玩家跑几轮，无重大 bug |
| 6 | 提交审核 → 上线 | 对外可见 |

**两条铁律**：自测必须在补物料之前；测试必须在正式上线之前。

### 9.1 运营节奏（TapTap 的流量是"事件驱动"的）

```
预约开启（首次有冷启动扶持 + 今日游戏位）
  → 封闭测试（定向推送，攒核心用户 + 评价）
  → 开放测试（冲新品榜）
  → 首发（今日游戏 15 天 + 冷启动 3 天）
  → 长线版本更新
```

注意：同一测试形式 90 天内只能上「今日游戏」一次 → **测试机会是稀缺资源，别浪费在小版本上。**

| 6 | Boss + 结算 + 烛泪 | 一局闭环完整 |
| 7 | 傩面 2 张 + 灯油 | 局外成长成立 |
| 8 | 物料（图标/截图/录屏/文案） | 可提审 |
| 9 | 自测 + 封闭测试 | 修 bug，收反馈 |
| 10 | 提审 → 试玩版上线 | 上架 |

**第 1 周结束的验收标准（最重要）**：自己连玩三局，中途不想关掉。做不到，就停下来改玩法，不要往下做美术。

## 11. 数据与验证指标

| 指标 | 及格 | 说明 |
|---|---|---|
| 商店页 → 试玩转化 | >8% | 低于此说明图标/首图不行，先换图 |
| 首局完成率 | >70% | 玩家是否玩完一局 |
| 平均单次时长 | >8 分钟 | 低于此说明钩子不成立 |
| 次日留存 | >25% | 肉鸽及格线 |
| 评分 | ≥8.0 | 低于 8 分几乎拿不到推荐位 |

**冷启动期只看一件事**：玩家在第几分钟流失最多。对照差评内容，两边指向同一处就是真问题。

## 12. 风险清单

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| 玩法"看起来不好玩"（截图无爽点） | 高 | 致命 | 首图用"满蜡 vs 残蜡"对比；录屏前 5 秒必出点亮一击 |
| 低蜡更安全的机制被玩成"龟缩流" | 高 | 中 | 蜡低于 30% 时攻击力衰减 + 强制刷"扑灯蛾"逼你动 |
| 暗黑题材被评 16+ 限流 | 中 | 中 | 主动标 16+，靠核心用户而非泛用户 |
| 版号拿不到 → 无法变现 | 高 | 高 | 一期做口碑和用户量，用数据换发行/版号合作 |
| 一个人做不完 | 中 | 高 | MVP 范围已钉死，只做一章 |
| 素材版权纠纷 | 低 | 致命 | 全部开源/原创，留凭证 |
